# voidale.github.io

Portfolio di **voidale**: programmatore e studente.

Sito statico (HTML, CSS e JavaScript), senza framework, senza tracciamento e senza richieste a servizi esterni: i caratteri sono inclusi nel sito.

## Contenuto
- Chi sono, cosa posso fare, **progetti** (Onda, Musica Desktop Widget), **timeline**, apprendimento e contatti.
- Domande frequenti su Onda.

## Progetti
- [Onda](https://github.com/VoidAle/Onda): lettore musicale per Windows (beta).
- [Musica Desktop Widget](https://github.com/VoidAle/desktop-widget): widget per Windows con musica, timer e volume.

`index.html`, `style.css`, `fonts.css`, `script.js`, `404.html`, `assets/` (immagini e caratteri). Le licenze di terze parti sono in `THIRD_PARTY_NOTICES.md`.
